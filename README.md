# general_research

This repository is for **general research** across mixed topics.

## How this repo is organized

- Each new research idea gets its own folder (typically under `research/`).
- Each research folder should include:
  - a `README.md` describing the question, method, caveats, and findings
  - a `.csv` file if there is tabular/source data
- Research topics are intentionally broad and may have different methodologies.
